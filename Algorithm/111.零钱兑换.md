111.零钱兑换
===


### 题目

给你一个整数数组 coins ，表示不同面额的硬币；以及一个整数 amount ，表示总金额。

计算并返回可以凑成总金额所需的 最少的硬币个数 。如果没有任何一种硬币组合能组成总金额，返回 -1 。

你可以认为每种硬币的数量是无限的。

 

示例 1：

- 输入：coins = [1, 2, 5], amount = 11
- 输出：3 
- 解释：11 = 5 + 5 + 1
示例 2：

- 输入：coins = [2], amount = 3
- 输出：-1

示例 3：

- 输入：coins = [1], amount = 0
- 输出：0

### 思路

这题最通俗的理解是：
- 你在凑钱，问“凑出指定金额，最少要拿几枚硬币”。
- 比如要凑 11 元，硬币有 1、2、5。
- 最省的方法其实是 5 + 5 + 1，一共 3 枚。


给你一些不同面额的硬币（无限供应），以及一个目标金额 amount，问：最少需要多少枚硬币才能凑出这个金额？​ 如果无法凑出，返回 -1。

例如：
- coins = [1, 2, 5]，amount = 11 → 最少需要 3 枚（5+5+1）
- coins = [2]，amount = 3 → 无法凑出 → 返回 -1
- coins = [1]，amount = 0 → 0 枚
