99.IPO
===


### 题目


假设 力扣（LeetCode）即将开始 IPO 。为了以更高的价格将股票卖给风险投资公司，力扣 希望在 IPO 之前开展一些项目以增加其资本。 由于资源有限，它只能在 IPO 之前完成最多 k 个不同的项目。帮助 力扣 设计完成最多 k 个不同项目后得到最大总资本的方式。

给你 n 个项目。对于每个项目 i ，它都有一个纯利润 profits[i] ，和启动该项目需要的最小资本 capital[i] 。

最初，你的资本为 w 。当你完成一个项目时，你将获得纯利润，且利润将被添加到你的总资本中。

总而言之，从给定项目中选择 最多 k 个不同项目的列表，以 最大化最终资本 ，并输出最终可获得的最多资本。

答案保证在 32 位有符号整数范围内。

 

示例 1：

- 输入：k = 2, w = 0, profits = [1,2,3], capital = [0,1,1]
- 输出：4
- 解释：
由于你的初始资本为 0，你仅可以从 0 号项目开始。
在完成后，你将获得 1 的利润，你的总资本将变为 1。
此时你可以选择开始 1 号或 2 号项目。
由于你最多可以选择两个项目，所以你需要完成 2 号项目以获得最大的资本。
因此，输出最后最大化的资本，为 0 + 1 + 3 = 4。

示例 2：

- 输入：k = 3, w = 0, profits = [1,2,3], capital = [0,1,2]
- 输出：6
 





### 思路

每次都在当前资金能做的项目中，选利润最高的来做。  

具体做法:  

1. 把所有的项目按所需资金从小到大排序
2. 用一个最大堆来存当前能做的项目的利润
3. 每次循环:   
    - 把所有资金门槛 <= 当前资金的项目，都加入最大堆
    - 从堆中取出利润最高的项目来做
    - 更新当前资金

4. 重复最多k次


为什么这样是对的？  

因为先做利润高的项目，能让资金增长更快，从而解锁更多高门槛的项目。  


```kotlin
import java.util.PriorityQueue

class Solution {
    data class Project(val capital: Int, val profit: Int)
    
    fun findMaximizedCapital(k: Int, w: Int, profits: IntArray, capital: IntArray): Int {
        val n = profits.size
        // 1. 把所有项目按所需资金排序
        val projects = Array(n) { Project(capital[it], profits[it]) }
        projects.sortBy { it.capital }
        
        // 2. 最大堆：存放当前能做的项目的利润
        val maxProfitHeap = PriorityQueue<Int> { a, b -> b - a }
        
        var currentCapital = w
        var projectIndex = 0
        
        // 3. 做最多 k 个项目
        repeat(k) {
            // 把所有资金门槛 ≤ 当前资金的项目加入堆
            while (projectIndex < n && projects[projectIndex].capital <= currentCapital) {
                maxProfitHeap.offer(projects[projectIndex].profit)
                projectIndex++
            }
            
            // 如果没有项目可做，提前结束
            if (maxProfitHeap.isEmpty()) return currentCapital
            
            // 选利润最高的项目来做
            currentCapital += maxProfitHeap.poll()
        }
        
        return currentCapital
    }
}
```


### 复杂度

- 时间复杂度:    O(n log n + k log n) — 排序O(n log n)，每次堆操作O(log n) 
- 空间复杂度:     O(n) — 存储项目和堆
