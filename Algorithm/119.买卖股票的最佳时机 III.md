119.买卖股票的最佳时机 III
===


### 题目

给定一个数组，它的第 i 个元素是一支给定的股票在第 i 天的价格。

设计一个算法来计算你所能获取的最大利润。你最多可以完成 两笔 交易。

注意：你不能同时参与多笔交易（你必须在再次购买前出售掉之前的股票）。

 

示例 1:
```
输入：prices = [3,3,5,0,0,3,1,4]
输出：6
解释：在第 4 天（股票价格 = 0）的时候买入，在第 6 天（股票价格 = 3）的时候卖出，这笔交易所能获得利润 = 3-0 = 3 。
     随后，在第 7 天（股票价格 = 1）的时候买入，在第 8 天 （股票价格 = 4）的时候卖出，这笔交易所能获得利润 = 4-1 = 3 。
```

示例 2：
```
输入：prices = [1,2,3,4,5]
输出：4
解释：在第 1 天（股票价格 = 1）的时候买入，在第 5 天 （股票价格 = 5）的时候卖出, 这笔交易所能获得利润 = 5-1 = 4 。   
     注意你不能在第 1 天和第 2 天接连购买股票，之后再将它们卖出。   
     因为这样属于同时参与了多笔交易，你必须在再次购买前出售掉之前的股票。
```
示例 3：
```
输入：prices = [7,6,4,3,1] 
输出：0 
解释：在这个情况下, 没有交易完成, 所以最大利润为 0。
```
示例 4：
```
输入：prices = [1]
输出：0
```


### 思路

我们可以把整个交易过程看做一个状态机，每个时间点处于以下五种状态之一: 

1. 未进行任何操作（初始状态）
2. 第一次买入后（持有第一支股票）
3. 第一次卖出后（已完成第一笔交易，空仓）
4. 第二次买入后（持有第二支股票） 
5. 第二次卖出后（已完成两笔交易，空仓）

我们只需要关注后四种状态（因为第一种状态利润恒为0，可以忽略）。每一天，我们可以选择不操作，或者从当前状态转移到下一个状态（买入或卖出）。

#### 状态定义

设四个变量：

- buy1：第一次买入后持有的最大利润（注意：买入意味着花钱，所以利润为负）
- sell1：第一次卖出后（完成第一笔交易）的最大利润
- buy2：第二次买入后持有的最大利润
- sell2：第二次卖出后（完成两笔交易）的最大利润

初始值：

- buy1 = -prices[0]（第一天买入，花费 prices[0]）
- sell1 = 0（第一天不可能卖出）
- buy2 = -prices[0]（第一天第二次买入，但必须先卖出第一次，但第一天无法卖出，所以 buy2 初始可以设为 -prices[0] 或 Integer.MIN_VALUE，但为了统一，我们稍后在遍历中处理）
- sell2 = 0

```kotlin
class Solution {
    fun maxProfit(prices: IntArray): Int {
        if (prices.isEmpty()) return 0

        var buy1 = -prices[0]
        var sell1 = 0
        var buy2 = Int.MIN_VALUE // 表示尚未进行第二次买入
        var sell2 = 0

        for (i in 1 until prices.size) {
            val p = prices[i]
            buy1 = maxOf(buy1, -p)
            sell1 = maxOf(sell1, buy1 + p)
            buy2 = maxOf(buy2, sell1 - p)
            sell2 = maxOf(sell2, buy2 + p)
        }

        return sell2
    }
}
```

### 复杂度

- 时间复杂度:     O(n)，只需遍历一次价格数组。
- 空间复杂度:     O(1)，只用了四个变量。
