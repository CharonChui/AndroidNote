76. 路径总和
===


### 题目

给你二叉树的根节点 root 和一个表示目标和的整数 targetSum 。

判断该树中是否存在 根节点到叶子节点 的路径，这条路径上所有节点值相加等于目标和 targetSum 。

如果存在，返回 true ；否则，返回 false 。

叶子节点 是指没有子节点的节点。

 

示例 1：

![Image](https://raw.githubusercontent.com/CharonChui/Pictures/master/leetcode_76_1.png?raw=true)
- 输入：root = [5,4,8,11,null,13,4,7,2,null,null,null,1], targetSum = 22
- 输出：true
- 解释：等于目标和的根节点到叶节点路径如上图所示。

示例 2：


- 输入：root = [1,2,3], targetSum = 5
- 输出：false
- 解释：树中存在两条根节点到叶子节点的路径：
    - (1 --> 2): 和为 3
    - (1 --> 3): 和为 4

不存在 sum = 5 的根节点到叶子节点的路径。

示例 3：

- 输入：root = [], targetSum = 0
- 输出：false
- 解释：由于树是空的，所以不存在根节点到叶子节点的路径。
 

提示：

- 树中节点的数目在范围 [0, 5000] 内
- -1000 <= Node.val <= 1000
- -1000 <= targetSum <= 1000


### 思路

与其问路径加起来等不等于targetSum，不如每走一步就问我还差多少？   

走到叶子时，如果还差的值正好等于叶子节点的值，就成功了。 

```kotlin
class Solution {
    fun hasPathSum(root: TreeNode?, targetSum: Int): Boolean {
        // 节点为空，说明走到头了也没找到
        if (root == null) return false

        // 走到叶子节点，判断剩余值是否等于当前节点的值
        if (root.left == null && root.right == null) {
            return targetSum == root.`val`
        }

        // 不是叶子节点，继续往左或往右走
        // 只要有一条路成功就返回 true
        val remaining = targetSum - root.`val`
        return hasPathSum(root.left, remaining) || hasPathSum(root.right, remaining)
    }
}
```


### 复杂度

- 时间复杂度: 时间 O(n)：最坏情况下每个节点都要访问一次
- 空间复杂度: 空间 O(h)：h 是树的高度，递归调用栈的深度，平衡树是 O(log n)，最坏退化成链表是 O(n)
